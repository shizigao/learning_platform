# 智能在线学习考试平台——项目设计报告图表代码

本文件按项目设计报告中的图号顺序整理。项目页面效果图需要从实际运行系统中截图，因此不在本文件中生成。其余用例图、架构图、模块图、部署图、ER 图、类图和时序图均提供可编辑代码。

使用方式：

1. `plantuml` 代码可粘贴到 PlantUML、IDEA PlantUML 插件或兼容的在线渲染器中。
2. `mermaid` 代码可粘贴到 Mermaid Live Editor、支持 Mermaid 的 Markdown 编辑器或相关 IDE 插件中。
3. 导出图片时优先使用 SVG 或 2 倍分辨率 PNG，再插入 Word 中对应的红色占位位置。

## 图 4-8 在线考试作答、交卷与评分时序图

```plantuml
@startuml
actor 考生
participant "Vue 答题页" as Front

Session -> Redis : 缓存截止时间/运行态
Session --> Front : 安全试题、服务器时间、截止时间

  考生 -> Front : 修改答案
  Front -> Controller : PUT /answers 或批量保存

  Answer -> DB : upsert exam_answer

考生 -> Front : 提交试卷

Submit -> DB : 行锁 + 状态改为 SUBMITTED
Submit -> Grade : gradeSubmittedAttempt(...)

Grade -> DB : 生成/刷新 exam_result
Submit -> Redis : 清除运行态
Submit --> Front : 提交结果

```

## 图 4-16 AI 资料总结与额度扣减规划时序图

```plantuml
@startuml
actor 用户
participant "Vue AI 学习助手" as Front
participant "AiController" as Controller
participant "AiTaskService" as Task
participant "TextExtractionService" as Extract
participant "AiClient" as AI
participant "EntitlementService" as Entitlement
database "MySQL" as DB

用户 -> Front : 对当前资料发起总结
Front -> Controller : POST /api/ai/contents/{id}/summaries
Controller -> Task : createSummaryTask(userId, contentId)
Task -> Entitlement : 检查 AI_QUOTA
Task -> DB : 创建 PENDING 任务
Task -> Extract : 提取图文/文档/字幕文本
Extract --> Task : 受限长度的资料文本
Task -> AI : 生成摘要、知识点、复习提纲

alt 调用与保存成功
  AI --> Task : 结构化结果
  Task -> DB : 保存 ai_summary\n任务标记 SUCCEEDED
  Task -> Entitlement : 原子扣减 AI_QUOTA
  Task -> DB : 保存 CONSUMED 使用记录
  Task --> Front : 返回总结
else 超时或失败
  AI --> Task : 错误/超时
  Task -> DB : 任务标记 FAILED\n记录脱敏错误
  Task --> Front : 提示稍后重试，不扣额度
end
@enduml
```

## 图 4-18 后续个性化学习闭环活动图

```plantuml
@startuml
start
:学习资料或参加考试;
:记录学习进度与答题结果;
if (存在错题或薄弱知识点?) then (是)
  :自动加入智能错题本;
  :标记错因并关联资料/知识点;
  :计算 1/3/7/30 天复习计划;
  :推送复习或变式题;
  if (连续多次答对?) then (是)
    :提升掌握度并延长复习间隔;
  else (否)
    :提供 AI 分步讲解与相似题;
  endif
else (否)
  :推荐下一章节或更高难度练习;
endif
:更新知识点掌握图、XP、连胜和周报;
stop
@enduml
```
