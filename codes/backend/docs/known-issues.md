# 已知问题与非阻断限制

更新日期：2026-07-24

OP-190 全量自动化验证未发现阻断性失败。当前保留以下 MVP 非阻断限制：

1. 支付仅为模拟支付，不代表真实资金交易；接入真实支付前必须补充签名、回调幂等、
   金额校验、退款和对账。
2. API 固定窗口限流为单实例内存实现；多实例部署前应迁移至 Redis 或 API 网关。
3. 操作日志 180 天清理由部署侧计划任务执行，当前应用本身不自动删除。
4. 本地 Docker Compose 只提供 Redis 与 MinIO，完整生产编排、TLS 和反向代理将在
   后续部署步骤中补齐。
5. 真实 AI 的响应时间和可用性受第三方服务影响；Mock 模式可用于无外网的功能验收，
   但不能替代真实供应商联调。

这些限制不影响当前 MVP 的本地开发、演示和核心流程验收。
