# 智能在线学习考试平台协作操作流程

## 一、文件用途

本文件是本项目从当前状态开发到 MVP 验收完成的顺序操作手册，与《项目说明.md》和《开发计划.md》配套使用。

每个步骤只能有一个主要执行角色：

- **【你】**：需要你在 VS Code、IntelliJ IDEA、浏览器、数据库工具、本机服务或第三方控制台中手动完成。
- **【AI】**：由 AI 在项目工作区内分析、创建或修改代码、生成脚本、执行命令行检查与测试。
- **【共同检查】**：你提供运行现象或日志，AI 分析结果；检查未通过时暂停后续步骤并修复。

建议逐项将 `- [ ]` 改为 `- [x]`。每完成一个“你”的步骤，请把步骤编号、执行结果和必要日志发给 AI，例如：

```text
已完成 OP-012。
JDK：17.0.x
Node.js：22.x
MySQL：8.0.x
异常：无
```

如果出现错误，请提供：步骤编号、完整报错文本、相关页面截图、后端控制台日志，以及触发错误前的操作。不要发送密码、Token、Access Key 或 AI API Key。

## 十三、每轮协作的固定操作顺序

项目实际开发时，每个小功能都使用以下循环，不跳过验证：

1. **【你】** 告诉 AI 当前执行到哪个 OP 编号，并确认前置步骤已完成。
2. **【AI】** 读取相关代码和文档，说明本轮将修改的范围。
3. **【AI】** 修改代码、SQL、配置模板或文档。
4. **【AI】** 执行能够在命令行完成的编译、构建和自动化测试。
5. **【AI】** 告诉你改动结果、测试结果和下一项需要手动执行的 OP 编号。
6. **【你】** 在 IDEA、VS Code、数据库工具或浏览器中执行该步骤。
7. **【你】** 返回成功结果；失败时返回完整日志和复现步骤，但隐藏所有密钥。
8. **【AI】** 分析并修复问题，重新执行自动化验证。
9. **【共同检查】** 当前检查点通过后，将对应复选框标为完成，再进入下一步。

## 十四、暂停与回退规则

- 任一阶段的“通过条件”未满足时，不进入依赖它的下一阶段。
- 数据库结构发生变化时，AI 必须同时更新迁移 SQL/初始化 SQL和实体映射；你只执行已明确标注目标环境的脚本。
- 执行删除表、清空数据、覆盖配置、回滚代码等破坏性操作前，AI 必须先说明目标和影响；你先备份并明确确认。
- 出现真实支付、生产数据迁移、公开部署、第三方账号授权等超出 MVP 默认范围的操作时，暂停并单独确认方案。
- 若需求变更，先更新《项目说明.md》《开发计划.md》和本文件的相关步骤，再修改代码。
- 密钥疑似泄露时立即停止相关服务，由你在对应平台轮换密钥；AI 负责清理代码和 Git 历史中的引用方案，但不接收新密钥。
